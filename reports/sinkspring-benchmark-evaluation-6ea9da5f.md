# SinkSpring 基准评估

- 任务：$id
- 评分口径：仅计入独立复核为 supported 的正式发现
- 标准集：30 个代码漏洞 + 5 个配置漏洞 + 7 个安全控制

## 严格结果

| 指标 | 结果 |
|---|---:|
| TP / FP / FN / TN | 5 / 0 / 30 / 7 |
| 精确率 | 100.00% |
| 总召回率 | 14.29% |
| 代码漏洞召回率 | 16.67% |
| 配置漏洞召回率 | 0.00% |
| 安全控制误报率 | 0.00% |
| 准确率（42 个标准实例） | 28.57% |
| F1 | 25.00% |
| Balanced accuracy | 57.14% |

命中：V13、V14、V18、V20、V24，分别为两个 SSRF、SpEL 表达式注入、JNDI 注入和反射型 XSS。

V23 JWT 验证绕过已形成候选但独立复核为 inconclusive，因此严格评分计为漏报。V22 只在 20 次预算的前一轮形成候选，本轮没有进入正式报告。

## 结论

取消常规 20 次上限后，正式召回从 0 提升到 5 个，说明原预算确实过早截断验证；但系统在 46 次调用后主动收口，仍漏掉 30/35 个标准漏洞。精确率和安全控制识别较好，主要瓶颈是路径预筛产生大量 sketch 后，只把其中少量路径推进到完整候选和独立复核；配置面完全没有转化为发现。当前投入产出为每个正式发现约 5.87 万 token、9.2 次模型调用和 2 分 15 秒。
